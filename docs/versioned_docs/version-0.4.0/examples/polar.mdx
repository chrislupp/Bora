# Polar sweep

A polar is the most common thing to ask of an airfoil code: the same section
at a range of angles of attack. With Bora it is a loop over one cheap
function. `examples/polar.rs` sweeps the quickstart airfoil from −8° to 18°
at three Reynolds numbers.

```bash
cargo run --release --example polar
```

<PolarFigure />

The figure is drawn from the example's own output. Three things in it are
worth noticing.

**Every point exists.** XFoil typically stops converging somewhere past
maximum lift, and a sweep comes back with holes. Here there are 105 points
per curve and no gaps. Whether the points beyond stall should be believed is
a separate question, which the confidence answers.

**The curves are smooth.** There is no scatter from one angle to the next and
no hysteresis: the result at 10° does not depend on whether the sweep arrived
from 9° or from 11°.

**The tangent is not fitted.** The line through the marked point has the slope
returned by `analyze_scalars_with_gradients` at that one angle. It is tangent
to a curve built from 105 independent evaluations.

## The loop

```rust title="examples/polar.rs (abridged)"
use bora::{AeroInput, AeroScalarResult, ModelSize, NeuralFoil, input_index};

fn main() -> bora::Result<()> {
    let mut input = AeroInput::default();
    input.kulfan.upper_weights = [0.24, 0.31, 0.25, 0.35, 0.24, 0.35, 0.28, 0.32];
    input.kulfan.lower_weights = [-0.12, -0.05, -0.13, 0.02, -0.08, 0.06, 0.02, 0.06];
    input.kulfan.leading_edge_weight = 0.02;
    input.kulfan.te_thickness = 0.0025;
    input.re = 1e6;

    let model = NeuralFoil::new(ModelSize::XLarge)?;

    for step in 0..=13 {
        let alpha = -8.0 + 2.0 * step as f64;
        let AeroScalarResult { output, gradient, .. } =
            model.analyze_scalars_with_gradients(&AeroInput { alpha, ..input });
        println!(
            "{alpha:>6.1}  {:>8.4}  {:>8.5}  {:>7.3}  {:>10.5}  {:>10.4}",
            output.cl,
            output.cd,
            output.top_xtr,
            gradient.cl[input_index::ALPHA],
            output.analysis_confidence
        );
    }
    Ok(())
}
```

`AeroInput` is `Copy`, so `AeroInput { alpha, ..input }` makes a modified copy
for each point without touching the original.

The lift-curve slope holds near 0.11 per degree through the linear range,
falls away beyond 6° and changes sign at 16°, which locates maximum lift
without a search. Upper-surface transition moves forward from 89% chord to
the leading edge as the angle rises, and from 4° upward the lower surface is
laminar to the trailing edge.

At a Reynolds number of 2 × 10⁵ the first row of the table tells a different
story: at −8° the confidence is 0.36 and the drag coefficient 0.08. The model
is reporting a largely separated flow and warning that it should not be
trusted there.

## Plotting

`--json` writes the outline and all three sweeps as JSON for a plotting
program:

```bash
cargo run --release --example polar -- --json > polar.json
```

The figures in this documentation are drawn from that file.
